# Instalación de WSL para usuarios con Windows. 
# Instala Ubuntu como subsistema Linux. Tenemos que ejecutar:
wsl --install Ubuntu

# Instala el plugin de VSCode 
https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl

# Arranca WSL con 
wsl 
# O con el siguiente si tienes varias distribuciones
wsl --distribution Ubuntu

# Ve al path donde esté el clone del proyecto y ejecuta
code .

# El proyecto se abrirá desde WSL
![Ejemplo WSL](https://microsoft.github.io/vscode-remote-release/images/remote-wsl-open-code.gif)
